# Create a song

Create guides you through four steps. You can return to any step using the numbered navigation.

1. **Sound:** enter a working title and describe the music. Use a starting idea or open the writing assistant to refine the description. Review suggestions before applying them.
2. **Words:** write lyrics or request a draft with your selected lyric model. Choose Instrumental for music without lyrics; existing written lyrics remain in the project. Include the desired language in your description when requesting a draft.
3. **Performance:** choose a vocal direction, rendering preset and number of takes. Advanced controls are optional. Generate submits the request and opens the results step when the queue accepts it.
4. **Listen:** follow generation progress, audition and compare candidates, choose favorites, download a take, or continue with stems, mastering, artwork and video.

The rendering preset changes acoustic synthesis effort. It does not guarantee a particular quality or exact song length. See [generation expectations](GENERATION-EXPECTATIONS.md) and [music adapters](MUSIC-ADAPTERS.md).

The writing assistant lets you select a model, generate, rewrite or continue text, and edit its suggestion before applying it. Optional models ask for download approval when first needed. Apply or save a draft before leaving the workspace; an unapplied suggestion is not a saved project edit.

## Continue in Studio

Open the same song in Studio to arrange tracks, edit notes and scores, mix, or analyze audio. Returning to Create preserves the project, assets, history and custom Studio settings. A custom configuration remains visible until you explicitly choose another preset.

The current step is remembered per project in this browser. Starting a blank project opens Sound; an existing project can open directly at its results. Navigation does not submit generation jobs or alter the arrangement.

Open **Guide** or press **F1** for help. Optional tours can be paused and replayed. Reduced-motion preferences disable animated step transitions.
